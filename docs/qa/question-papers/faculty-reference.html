Run checks before submitting. AI provides suggestions only; staff remain responsible for the final paper.

Submission workflow

What happens after you submit

1. Staff submits PDF set

Upload the question paper and select the examination details.

2. Department HOD reviews

HOD approves one set or returns it with revision comments.

3. Approved set is forwarded

The selected paper is sent to COE / Exam Control and the main admin workflow.

ⓘKeep the paper confidential. Do not include student names or share question-paper files outside the approved workflow.
