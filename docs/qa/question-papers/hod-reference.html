HOD review checklist

Before approving a set

1
Confirm syllabus and blueprint

Verify unit coverage, learning outcomes, marks distribution and exam duration.

2
Compare the submitted sets

Review Balanced, Moderate and Advanced versions; check fairness and academic standard.

3
Approve one official paper

Select a single version. Return the others or retain them as restricted alternatives per policy.

4
Forward to COE / Exam Control

Record approval and transmit the selected PDF with the approval timestamp.

ⓘConfidentiality: Approval actions must be auditable. Keep every version restricted and record who approved the final paper.
